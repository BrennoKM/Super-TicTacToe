## Como usar este arquivo

- O agente lê este arquivo no início de toda tarefa relevante (implementar, validar, etc.).
- Toda regra aqui é tão inegociável quanto as universais.
- Adicione regra nova quando o time tomar uma decisão que aplica a todo trabalho daqui pra frente (não a uma demanda específica).
- Remova/atualize regra quando ela ficar obsoleta.
